# Sources and licenses

- **std-t98-receiver / SPEAR** (GPL-3.0): selected-channel 4FSK DSP, synchronization, frame parsing and protocol vectors in `third_party/spear`; selected-bin channelizer and core types in `native`. Sources: https://github.com/tallcat4/std-t98-receiver and https://github.com/tallcat4/SPEAR . The input adapter resamples SDR# selected-channel IQ to 50 kHz (8 × 6250 Hz) and adds automatic frequency correction.
- **SPEAR** (GPL-3.0): native solver-guided AI (`guided.cpp/.hpp`), PN series and bit-order helpers in `native/secret` and `native/ambe`. The real-time session design follows `apps/std_t98/secret/worker.cpp`, `tracker.cpp`, and the traffic handling in `std_t98_app.cpp`: bounded overlapping windows with absolute burst offsets, independent inference, session-bound results, revocation and discontinuity resets. The C# worker calls native code directly on its own thread.
- **std-t98-cracker** (GPL-3.0): reference implementation in `tests/reference/std_t98_cracker`, solver-guided AI and original model weights in `models`. https://github.com/tallcat4/std-t98-cracker . Model and solver parameters are the upstream defaults; the UI exposes no algorithm configuration. `native/secret/hybrid.cpp` evaluates the original architecture and FP32 weights using SSE2; it does not quantize or retrain the model. `tools/check-native-model.py` compares logits against the original PyTorch implementation. Model SHA256: `e7093ed37bfe7d70b29872bfb55dece47cf3398af4dc4aab6e9c1a806ad5f418`.
- **std-t98-vocode / ambe2-c**: FEC and AMBE+2 synthesis, including the natural/ThumbDV ordering contract. https://github.com/tallcat4/std-t98-vocode and https://github.com/tallcat4/ambe2-c . Codec source is pinned to `70e32cbfc1cf5a08f3e9a3fbe41f6a9873cc4ca6`. See `licenses/ambe2-c.txt` for its MIT notices, including OpenBLIP25 and other upstream authors.
- **FFTW 3.3.5**: single-precision Windows x64 runtime. See `licenses/fftw.txt` and https://www.fftw.org . Its runtime is bundled; SDR# is not bundled.
- **Python, NumPy, PyTorch and safetensors** are development/test dependencies only. No Python runtime, CUDA, ONNX Runtime or external model download is required or bundled in the plugin.

The corresponding plugin, native adapter, bundled upstream source and model weights are included in the source archive produced by `tools/package.ps1`.
